# 🕰️ Sandarbh (संदर्भ) — Full-Stack Vintage & Antique Marketplace

**Sandarbh** is a full-stack web application designed for discovering, buying, and selling pre-loved, vintage, and antique items such as classic watches, clothing, retro collectibles, and rare artifacts. 

---

## 🚀 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+, DOM Manipulation, Fetch API)
* **Backend:** Node.js, Express.js (RESTful APIs, Static File Serving, CORS)
* **Database:** MySQL (Relational Database Management System)
* **Database Driver:** `mysql2`
